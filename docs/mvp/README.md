## Estado documentado

MVP funcional em desenvolvimento local para web. A documentação distingue recursos implementados, evidências de testes e propostas futuras. A base sintética não representa usuários reais; os perfis de QA sem identidade Firebase não possuem login. O uso escolar e a avaliação com participantes permanecem etapas futuras.

## Manutenção

Edite `MVP_CONEXIA.md` nesta pasta para atualizar o produto e registre a data e a versão. Diferencie contagens do seed de totais atuais do banco e testes automatizados de validação com usuários. Relatórios de auditoria anteriores registram etapas históricas.

Esta pasta reúne apenas documentação. Credenciais, senhas, tokens, bancos locais e backups não devem ser adicionados ao Git.
